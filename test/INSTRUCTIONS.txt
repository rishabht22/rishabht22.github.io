7. 3D MODEL PIPELINE (for future robots)
----------------------------------------
- From Fusion 360: File -> Export -> FBX, refinement Medium. Don't commit it.
- Tools (installed once in a temp folder, NOT in the repo):
    npm install fbx2gltf @gltf-transform/cli
- Convert:  FBX2glTF --binary --input robot.fbx --output robot-raw
- Fusion is Z-up; the web viewer is Y-up. Wrap the scene in a node rotated
  -90deg about X (quaternion [-0.7071, 0, 0, 0.7071]), then center x/z and
  set min y = 0 (see the @gltf-transform/core script approach used for
  Purple Emperor). Check orientation by finding the drivetrain node's bounds.
- Compress:  gltf-transform optimize in.glb out.glb --compress draco
             --texture-compress false --simplify-error 0.0008
- Put the .glb + a rendered .webp poster in test/projects/<name>/.
