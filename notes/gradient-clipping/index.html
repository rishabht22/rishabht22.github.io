Bias and Convergence in Gradient-Clipped SGD

Intro

A large gradient can produce a step that’s far too large. Gradient clipping puts a limit on it. Each gradient keeps its direction and gets shorter if needed.

But SGD uses random gradients. Shrinking some of them more than others changes their average. The average can even end up pointing the other way, so a small update can still go uphill [1].

Clipping an exact gradient

We’ll use Euclidean norm clipping with threshold \(c>0\). It scales the whole vector, keeping gradients inside the ball of radius \(c\) unchanged.

\[ C_c(g)=g\min\!\left(1,\frac{c}{\|g\|}\right) \quad(g\ne0),\qquad C_c(0)=0. \]

The update is \(\theta^+=\theta-\eta C_c(g)\), with learning rate \(\eta>0\). First suppose \(g=\nabla f(\theta)\) is exact. For a nonzero gradient, write \(C_c(g)=\alpha g\), where \(0<\alpha\leq1\). The update direction has

\[ \nabla f(\theta)^\top(-\eta\alpha\nabla f(\theta)) =-\eta\alpha\|\nabla f(\theta)\|^2<0. \]

So it’s still a descent direction. If \(f\) has an \(L\)-Lipschitz gradient, the descent lemma gives

\[ f(\theta^+)\leq f(\theta) -\eta\alpha\left(1-\frac{L\eta\alpha}{2}\right) \|\nabla f(\theta)\|^2. \]

A step satisfying \(0<\eta\alpha<2/L\) lowers the objective. In this setting, clipping works like a smaller learning rate for that step.

A random gradient can behave differently

Now let \(g\) be an unbiased stochastic gradient, so \(\mathbb E[g\mid\theta]=\nabla f(\theta)\). Hold \(\theta\) fixed in the expectations below. Clipping gives each draw a weight \(w(g)=\min(1,c/\|g\|)\), with \(w(0)=1\). Its expected value is

\[ \mathbb E[C_c(g)]=\mathbb E[w(g)g] \ne \mathbb E[w(g)]\,\mathbb E[g] \quad\text{in general}. \]

The weight depends on the gradient it multiplies. Large gradients lose more of their contribution. If those gradients tend to point one way, clipping changes the balance between directions. The resulting bias depends on the gradient distribution, not just its mean [2].

A convex example that moves uphill

Consider these one-dimensional sample objectives.

\[ f_\xi(\theta)=\frac12\theta^2+\xi\theta, \qquad \xi=\begin{cases} 1 & \text{with probability }0.9,\\ -19 & \text{with probability }0.1. \end{cases} \]

The full objective is \(f(\theta)=\mathbb E[f_\xi(\theta)]=\tfrac12\theta^2-\theta\), with minimizer \(\theta^*=1\). Its sample gradient is \(g=\theta+\xi\). At \(\theta=0\), clipping at \(c=1\) gives

\[ \begin{aligned} \mathbb E[g]&=0.9(1)+0.1(-19)=-1,\\ \mathbb E[C_1(g)]&=0.9(1)+0.1(-1)=0.8. \end{aligned} \]

SGD subtracts the gradient. Before clipping, the expected step goes right, toward the minimizer. After clipping, it goes left. The rare negative gradients were large enough to outweigh the frequent positive ones. Clipping removes that difference in size.

We can check the loss itself. Since \(C_1(g)\in\{-1,1\}\), the next parameter is \(\theta^+=-\eta C_1(g)\). Therefore

\[ \mathbb E[f(\theta^+)]-f(0) =\frac{\eta^2}{2}+0.8\eta>0. \]

Every positive learning rate raises the expected objective in this example. This is an exact calculation, with no neural network or approximation involved.

Why a smaller learning rate doesn’t remove the bias

Smaller steps reduce how far the update goes. They don’t change its expected direction. The same example also has a point where the expected clipped update is zero even though the true gradient isn’t.

For \(-2<\theta<0\), the sample gradient \(\theta+1\) stays unclipped while \(\theta-19\) is clipped to \(-1\).

\[ \mathbb E[C_1(g)]=0.9(\theta+1)-0.1 =0.9\theta+0.8. \]

This is zero at \(\theta=-8/9\). The true minimizer is still \(1\). Making \(\eta\) smaller doesn’t move this zero. It also doesn’t mean a random run stops there, since individual updates still have noise.

More generally, clipped SGD can have a convergence error that survives shrinking the learning rate under standard bounded-variance assumptions [1].

Averaging before clipping

There are two different ways to use a batch of gradients.

\[ \underbrace{C_c\!\left(\frac1B\sum_{i=1}^B g_i\right)}_{\text{average, then clip}} \qquad\text{and}\qquad \underbrace{\frac1B\sum_{i=1}^B C_c(g_i)}_{\text{clip, then average}}. \]

If the samples have the same distribution, the second expression has expectation \(\mathbb E[C_c(g)]\) for every batch size. More samples can reduce its variance, but the clipping bias stays.

The first expression behaves differently. Suppose the samples are independent and unbiased, with \(\mathbb E\|g_i-\mu\|^2\leq\sigma^2\), where \(\mu=\nabla f(\theta)\). Let \(\bar g_B\) be their average. Euclidean clipping is a projection onto a ball, so it cannot increase the distance between two vectors. This gives

\[ \begin{aligned} \left\|\mathbb E[C_c(\bar g_B)]-C_c(\mu)\right\| &\leq\mathbb E\|\bar g_B-\mu\|\\ &\leq\sqrt{\mathbb E\|\bar g_B-\mu\|^2} \leq\frac{\sigma}{\sqrt B}. \end{aligned} \]

As the batch grows, this approaches clipping the exact gradient. The magnitude can still be reduced, but the extra error from clipping noisy samples shrinks. Batch size and gradient alignment are also studied in [3].

For the example above, averaging ten independent samples before clipping gives an expected clipped gradient of \(2(0.9)^{10}-1\approx-0.303\). Its sign now agrees with the true gradient. Clipping each sample first would still give \(0.8\).

Using it in training

Clipping limits the SGD step norm to \(\eta c\). That can be useful when occasional gradients would otherwise produce huge updates. There are also convergence results showing benefits under smoothness conditions that allow curvature to grow with the gradient norm [4].

The threshold trades off that protection against the bias introduced by shrinking different samples unequally. With a fixed threshold, increasing the batch size before clipping can help under the assumptions above. No single threshold works best for every gradient distribution.

The same calculation applies to an unbiased stochastic policy gradient when taking a plain gradient step. For Adam, clipping bounds the gradient passed into the optimizer, not the final update after its adaptive scaling. PPO’s likelihood-ratio clipping is a separate operation from gradient norm clipping.

Summary

Clipping an exact gradient preserves a descent direction. Clipping a random gradient can change its mean enough to reverse it or create a zero at the wrong point. A smaller learning rate doesn’t remove that bias. Averaging independent samples before clipping can reduce it, while averaging already clipped samples keeps the same expected bias.
